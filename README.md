# BlockLock

BlockLock is a macOS application designed to help you stop procrastinating and manage your time effectively. 

## Features
- **Main Planner**: Plan your tasks and focus sessions effectively.
- **Overlay Window Manager**: Overlays to prevent distractions when you are supposed to be working.
- **Micro Reminders**: Small reminders to keep you on track during your work.
- **Background Scheduler**: Manages and schedules background tasks for your anti-procrastination needs.

## Requirements
- macOS 14.0+

## Build and Run
This project is built using Swift Package Manager.

To build and run from the terminal:
```bash
swift run
```

Alternatively, you can open `Package.swift` in Xcode to build and run the application.
